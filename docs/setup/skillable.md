# Skillable: guided C# labs

[All options](../../README.md#choose-your-route) | [Public C# track and prerequisite notes](../tracks/csharp.md)

Choose this option when your course includes the fully guided Skillable environment. **This option is C# only in this guide.**

## Access and prerequisites

**Your trainer will provide you with a lab key and instructions on how to log in.** There is no assumed public launch URL.

Have your own GitHub account and [Copilot access](https://docs.github.com/en/copilot/get-started/plans) available. A hosted environment does not automatically provide a Copilot entitlement or bypass organization policies. Follow your trainer's access and environment-readiness guidance; do not install a local toolchain just to use this option.
