## Prerequisite reminder and original setup links

- Own GitHub account and [Copilot access](https://docs.github.com/en/copilot/get-started/plans).
- Git 2.48+, Python 3.10+, VS Code 1.116+, and the VS Code Python extension.
- [Original Python setup instructions](https://microsoftlearning.github.io/mslearn-github-copilot-dev/Instructions/Labs/LAB_AK_00_configure_lab_environment_py.html).
- [Original Copilot activation instructions](https://microsoftlearning.github.io/mslearn-github-copilot-dev/Instructions/Labs/LAB_AK_00_enable_github_copilot_in_visual_studio_code.html).

Use the [Microsoft source repository](https://github.com/MicrosoftLearning/mslearn-github-copilot-dev). Each Python exercise 02-05 names a different starter under `LabFiles`; follow that selection rather than opening a similarly named C# project. Setup and verification steps remain in the original instructions.
