# Your computer + VS Code: C#

[All options](../../README.md#choose-your-route) | [C# coverage and project notes](../tracks/csharp.md)

Use this route for the Microsoft C# exercises on your own machine.

## Prerequisite reminder and original setup links

- Your own GitHub account with [Copilot access](https://docs.github.com/en/copilot/get-started/plans); organization policies and usage limits still apply.
- Git 2.48+, VS Code 1.116+, C# Dev Kit, .NET SDK 9.0+, and any runtimes required by the selected starter.
- [Original C# setup instructions](https://microsoftlearning.github.io/mslearn-github-copilot-dev/Instructions/Labs/LAB_AK_00_configure_lab_environment.html).
- [Original Copilot activation instructions](https://microsoftlearning.github.io/mslearn-github-copilot-dev/Instructions/Labs/LAB_AK_00_enable_github_copilot_in_visual_studio_code.html).

Sample code comes from the [Microsoft lab repository](https://github.com/MicrosoftLearning/mslearn-github-copilot-dev). Each original exercise identifies the project to open; 02-05 have separate library starter folders, and later exercises switch applications. This guide contains neither the sample code nor copied setup steps.
