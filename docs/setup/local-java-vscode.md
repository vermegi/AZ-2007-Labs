# Your computer + VS Code: Java

[All options](../../README.md#choose-your-route) | [Java track](../tracks/java.md)

**Experimental community adaptation.** This is native local development, without Docker or Codespaces.

## Prerequisite reminder and original setup links

- Own GitHub account and [Copilot access](https://docs.github.com/en/copilot/get-started/plans).
- Git 2.48+, VS Code, Java 21 LTS, Maven 3.9+, and VS Code's Java support.
- [Original Java local-machine setup and readiness checks](https://github.com/mkennten/mslearn-github-copilot-dev-java/blob/main/Instructions/Labs/LAB_AK_00_configure_lab_environment.md#local-machine-requirements).
- [Original Copilot access checks](https://github.com/mkennten/mslearn-github-copilot-dev-java/blob/main/Instructions/Labs/LAB_AK_00_configure_lab_environment.md#verify-github-copilot-access).

Use the [Java source repository](https://github.com/mkennten/mslearn-github-copilot-dev-java). Its `AccelerateDevGHCopilot` folder contains the Maven project for 01-05; 06 creates a new web prototype. The original source contains the clone, open, build, and run steps.
