## Preparation

- [Python environment prerequisites and setup](https://microsoftlearning.github.io/mslearn-github-copilot-dev/Instructions/Labs/LAB_AK_00_configure_lab_environment_py.html).
- [Enable Copilot in VS Code](https://microsoftlearning.github.io/mslearn-github-copilot-dev/Instructions/Labs/LAB_AK_00_enable_github_copilot_in_visual_studio_code.html).
- Reminder: Git 2.48+, Python 3.10+, VS Code 1.116+ with the Python extension, and your own GitHub account with [Copilot access](https://docs.github.com/en/copilot/get-started/plans).

The source exercises select different starter folders. Do not assume the previous exercise's project is the next starter.

**Stop this track after 06.** Exercises 07-16 use C#/.NET applications and have no supplied Python variants. In particular, 13-14 require Python for Spec Kit tooling but are not Python application labs. No .NET SDK, C# Dev Kit, xUnit, Spec Kit setup, or Copilot SDK setup is required for this Python route.

Skillable, Codespaces, and local Dev Containers are not Python options in this guide.
